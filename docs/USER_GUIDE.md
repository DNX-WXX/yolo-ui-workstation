# YOLO UI Workstation 使用文档

本文档详细介绍每个功能板块的作用和操作方法。

---

## 界面总览

主界面为 5 个标签页，按工作流程从左到右排列：

| 标签页 | 功能 | 快捷键 |
|--------|------|--------|
| 0. 数据集管理 | 数据集格式转换、图像预处理 | `Ctrl+1` |
| 1. 模型训练 | 配置训练参数并启动训练 | `Ctrl+2` |
| 2. 模型验证 | 验证训练好的模型性能 | `Ctrl+3` |
| 3. 模型推理 | 用模型进行图像/视频推理 | `Ctrl+4` |
| 4. 模型部署 | 导出部署格式、模型压缩 | `Ctrl+5` |

---

## 0. 数据集管理

### 功能概述

将原始标注数据（VOC / COCO / YOLO）转换为统一的 YOLO 训练格式，并进行图像预处理。包含两个子标签页：

### 子标签页 1：数据集转换

**作用**：把 VOC / COCO / YOLO 等格式的标注数据整理为统一的 YOLO 训练目录结构。

**操作步骤**：

1. **自动识别源格式** — 支持 YOLO、VOC、COCO 及分类文件夹结构
2. **选择任务类型** — detect / segment / pose / classify
3. **输入路径** — 选择原始数据集文件夹（或拖拽到输入框）
4. **输出路径** — 选择转换后数据集的保存位置
5. **数据集划分** — 设置 train / val / test 比例（如 0.8 / 0.1 / 0.1）
6. **开始转换** — 点击按钮，后台执行，进度条实时更新

**输出目录结构**：

```
output/
├── data.yaml             # 自动生成的训练配置文件
├── images/
│   ├── train/
│   ├── val/
│   └── test/
└── labels/
    ├── train/
    ├── val/
    └── test/
```

**注意事项**：
- 分类任务无需标注文件，只需按类别分文件夹存放图片
- COCO 转 segment 使用 `use_segments=True`，转 pose 使用 `use_keypoints=True`
- 不支持的任务：obb、semantic、depth

### 子标签页 2：图像预处理

**作用**：批量处理图像，确保训练数据质量。

**功能项**：
- **去重** — 基于 MD5 哈希检测重复图片，自动去重
- **损坏检测** — 识别无法打开或损坏的图片文件
- **尺寸调整** — 批量缩放到目标尺寸，支持填充 / 裁剪两种模式（关闭“保持比例”即为拉伸）
- **格式统一** — 保持原文件扩展名，RGBA / 灰度图自动转为 RGB

**操作步骤**：
1. 选择输入文件夹和输出文件夹
2. 设置目标尺寸（如 640×640）
3. 勾选需要的处理项（去重 / 去损坏 / 缩放 / 跳过已存在文件）
4. 点击开始，后台批量执行

## 1. 模型训练

### 功能概述

配置训练参数并启动 YOLO 模型训练，实时显示训练进度与关键指标。

### 训练配置子标签页

按从上到下顺序，共有 6 个配置分组：

**1. 任务与模型**
- **任务类型**：detect / segment / classify / pose / semantic / depth / obb
- **模型版本**：YOLOv5 / YOLOv8 / YOLO11 / YOLO26
- **预训练模型**：下拉框自动列出当前任务+版本兼容的模型（如 yolo11n.pt）
- **模型选择方式**：使用预训练模型（自动下载）或加载本地 .pt 文件

> 切换任务类型时，预训练模型列表会自动刷新为兼容模型。

**2. 数据集配置**
- **数据集路径**：选择转换后的数据集文件夹（含 data.yaml）
- **数据集 YAML**：自动识别 data.yaml 路径

**3. 训练参数**
- **Epochs**：训练轮数（默认 300）
- **Batch Size**：批次大小（默认 8，根据显存调整）
- **图像尺寸**：输入图像大小（默认 640）

**4. 学习率**
- **初始学习率**（lr0）：默认 0.01
- **学习率调度**：cos / linear / step / plateau

**5. 优化器配置**
- **Optimizer**：auto / SGD / Adam / AdamW / RMSProp
- **LR Schedule**：cos / linear / constant
- **Warmup Epochs**：预热轮数（默认 3）
- **Warmup LR**：预热学习率（默认 0.01）
- **Weight Decay**：权重衰减（默认 0.0005）
- **Momentum**：动量（默认 0.937）

> 大部分场景保持默认值即可。不确定时使用 `auto`。

**6. 数据增强**
- **Mosaic**：马赛克增强概率（0~1，检测/分割建议 1.0，分类建议 0.0）
- **MixUp**：混合增强概率
- **Copy-Paste**：复制粘贴增强概率
- **Flip LR**：水平翻转概率
- **HSV-H / HSV-S / HSV-V**：色调/饱和度/亮度调整幅度
- **Degrees**：旋转角度范围

> 取消勾选整个分组可关闭数据增强。切换任务类型时，这些值会自动调整为该任务的推荐配置。

### 训练过程查看

训练启动后，配置页下方即为实时状态区：

- **进度条**：当前 epoch / 总 epoch 进度
- **Epoch / 指标**：当前 epoch 编号与 mAP50 / Top-1 Acc 实时数值
- **训练日志**：显示每个 epoch 的详细输出
- **停止训练**：中途终止训练

训练结束后，点击"打开输出文件夹"，ultralytics 已在 `runs/` 对应实验目录下自动生成完整结果：

- `results.png`：Loss、mAP、精确率/召回率曲线总览
- `results.csv`：逐 epoch 的完整指标数据
- `confusion_matrix.png` / `PR_curve.png` / `F1_curve.png`：评估图表
- `train_batch*.jpg` / `val_batch*.jpg`：训练与验证样本预览
- `weights/best.pt`、`weights/last.pt`：最佳与最后一轮权重

### 操作步骤

1. 在训练配置页完成任务与模型选择
2. 设置数据集路径
3. 按需调整训练参数（或保持默认）
4. 点击"开始训练"
5. 在下方实时状态区查看进度、指标与日志
6. 训练完成后模型保存在输出目录中，点击"打开输出文件夹"查看曲线与评估图表

## 2. 模型验证

### 功能概述

对已训练好的模型进行性能验证，输出精度指标。

### 操作步骤

1. **选择模型文件** — 加载 .pt 模型（支持拖拽）
2. **选择数据集** — 指定验证用的数据集路径
3. **配置验证参数** — batch size、图像尺寸、置信度阈值等
4. **开始验证** — 执行 `model.val()`
5. **查看结果**：
   - **指标**子页：mAP50、mAP50-95、Precision、Recall 等
   - **详细日志**子页：每个类别的详细指标

## 3. 模型推理

### 功能概述

使用训练好的模型进行推理，支持多种输入源。

### 配置区域

**任务与模型**：
- 任务类型：detect / segment / classify / pose / semantic / depth / obb
- 模型文件：选择 .pt 或 .onnx 模型

**推理参数**：
- **置信度阈值**：过滤低置信度结果（默认 0.25）
- **NMS 阈值**：非极大值抑制阈值（默认 0.45）
- **图像尺寸**：推理输入尺寸

**跟踪模式**（可选，分类任务不启用）：
- 勾选"启用跟踪"后，为每个目标分配 ID 并绘制运动轨迹
- 支持跟踪器：ByteTrack / BotSORT / DeepSORT

### 推理模式

| 模式 | 说明 |
|------|------|
| 单张图像 | 选择一张图片进行推理 |
| 文件夹 | 批量推理文件夹中所有图片 |
| 视频 | 对视频文件逐帧推理 |
| 摄像头 | 实时摄像头推理 |

### 操作步骤

1. 加载模型文件
2. 选择推理模式（图像 / 文件夹 / 视频 / 摄像头）
3. 调整置信度等参数
4. 如需跟踪，勾选"启用跟踪"
5. 点击"开始推理"
6. 在右侧查看推理结果，支持缩放查看

## 4. 模型部署

### 功能概述

将训练好的 .pt 模型导出为 ONNX 格式，并进行模型压缩与知识蒸馏。

### ONNX 导出

**操作步骤**：
1. 选择已训练的 .pt 模型
2. 配置导出参数（输入尺寸、opset 版本、批处理、动态批处理、NMS、ONNX 简化等）
3. 选择量化精度：FP32（默认）/ FP16（推荐）/ INT8（PTQ 量化，需提供校准数据集 YAML）
4. 点击"开始转换"导出 ONNX 模型
5. 可选：选择测试图片，对比 PT 与 ONNX 模型的预测结果

### 模型压缩

- **知识蒸馏**：用大模型（教师）指导小模型（学生）训练
  - 支持系列：YOLOv8 / YOLO11 / YOLO26
  - 限制：教师与学生须同一家族（跨家族蒸馏不受支持）
  - 支持任务：目标检测、实例分割、姿态估计、旋转框检测

## 通用功能

### 拖拽操作

所有文件/文件夹输入框都支持直接拖拽文件到输入框。

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+1` ~ `Ctrl+5` | 切换标签页 |
| `Ctrl+Q` | 退出程序 |
| `F1` | 显示帮助 |
| `F11` | 切换全屏 |
| `Ctrl++` / `Ctrl+-` | 放大/缩小图像 |
| `Ctrl+滚轮` | 缩放图像 |
| `Ctrl+0` | 适应窗口 |
| `Ctrl+H` | 显示/隐藏图像信息浮层 |
| `Ctrl+Shift+C` | 复制当前图片路径 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 切换标签页 |
| `Ctrl+N` / `Ctrl+P` | 下一张/上一张图片 |

### 任务类型与模型后缀对照

| 任务 | 后缀 | 示例模型名 |
|------|------|-----------|
| detect | (无) | yolo11n.pt |
| segment | -seg | yolo11n-seg.pt |
| classify | -cls | yolo11n-cls.pt |
| pose | -pose | yolo11n-pose.pt |
| semantic | -sem | yolo26n-sem.pt |
| depth | -depth | yolo26n-depth.pt |
| obb | -obb | yolo11n-obb.pt |

### 版本兼容性速查

| 版本 | 支持任务 | NMS |
|------|---------|-----|
| YOLOv5 | detect, classify | 可选 |
| YOLOv8 | detect, segment, classify, pose, obb | 可选 |
| YOLO11 | detect, segment, classify, pose, obb | 可选 |
| YOLO26 | detect, segment, semantic, depth, classify, pose, obb | 内置 |
